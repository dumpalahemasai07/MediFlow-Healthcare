# MediFlow Healthcare

A modern healthcare appointment and doctor management web application built using React, Vite, TypeScript, and Supabase.

---

## Features

* Doctor listing and profiles
* Appointment booking system
* Authentication system
* Modern responsive UI
* Supabase integration
* Fast Vite development setup
* TypeScript support

---

## Tech Stack

* React
* TypeScript
* Vite
* Supabase
* Tailwind CSS
* TanStack Router

---

## Installation

Clone the repository:

```bash id="u1k9pq"
git clone https://github.com/your-username/MediFlow-Healthcare.git
```

Go to the project folder:

```bash id="d4x7mn"
cd MediFlow-Healthcare
```

Install dependencies:

```bash id="g8w2ta"
npm install
```

Run development server:

```bash id="y5q3rv"
npm run dev
```

---

## Build Project

To create production build:

```bash id="n2p6sk"
npm run build
```

---

## Preview Production Build

```bash id="h7m1zc"
npm run preview
```

---

## Environment Variables

Create a `.env` file in the root directory and add:

```env id="q4r8bv"
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
